## 常见问题

**Claude Pro 有学生优惠吗？**
没有。个人不提供学生折扣，教育优惠只通过 Claude for Education 的院校合作进行，学生订阅按标准价付费。

**哪里能找到官方优惠码？**
官方没有常设优惠码。限时促销会通过官方社交账号和邮件通知发布，遇不上也不用纠结，年付本身就是最大的官方折扣。

**月付还是年付划算？**
确定会用两个月以上就选年付，$200/年比月付省 $40。还在观望就先月付，反正随时能取消。

**订阅后可以取消吗？**
可以。在设置的 Billing 页面取消，套餐保留到已付费周期结束，不会扣下一期。

**用量用完了怎么办？**
等 5 小时窗口重置，或开启用量 credits 继续用，长期超限再考虑升级 Max。

**Pro 包含 API 额度吗？**
不包含。API 按 token 单独计费，和订阅是两套体系，做开发要单独做预算。
